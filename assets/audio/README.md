# Âm thanh

Mixer của StudyNest tạo mưa, gió, sóng biển, lửa, quán cà phê, bàn phím và ba màu noise bằng Web Audio API ngay trong trình duyệt. Vì vậy phiên bản này không cần file âm thanh ngoài và vẫn dùng được khi offline. Trình phát lofi dùng link do người dùng chọn, phát qua YouTube, Spotify hoặc SoundCloud khi có mạng.
